# Weight Tracking App

## Mobile App Summary
The app I developed is a Weight Tracking App that lets users create an account, log in, record their weight, set a goal weight, and track their progress over time. The main goal was to give users a simple way to keep track of their weight in one place instead of having to write it down or use a spreadsheet. I also added an optional SMS permission screen to show how the use of Android permissions would work here.

## User-Centered Design
To support the user's needs, I created a login screen, account creation screen, dashboard, add weight screen, goal weight screen, and an SMS permission screen. I wanted each screen to focus on only one task so it would be easy for users to understand what to do next and what they are currently having to do. I used a consistent color theme, clear labels, and simple navigation throughout the app. I think these design choices made the app easy to use, especially for someone opening it for the very first time.

## Development Process
When I was coding the app, I focused on completing one feature at a time instead of trying to build everything all at once. I started by creating the user interface, then connected the different screens before adding the SQLite database and the rest of the functionality. After each feature was finished, I tested it before I moved on to the next one. Breaking the project into smaller steps helped me to stay organized and also made it much easier to solve any problems that came up. I think this is a strategy I will keep using in my future projects.

## Testing
I tested the app while I was developing it by running it in the Android Emulator after making any changes. I created test accounts, logged in, added weight entries, updated goal weights, and made sure that the information was being stored porperly in the database. I also tested that every button and screen navigation worked like it should. Testing was important because it helped me catch mistakes earlier on instead of waiting until the end of the project.

## Challenges
One of the biggest challenges was getting all of the different parts of the application to work together correctly. There were several screens, activities, and database functions that all needed to communicate with each other. Whenever I ran into a problem, I usually broke it down into smaller pieces and tested each one until I eventually found the issue. Working through those challenges helped me to understand more about how Android applications are really built.

## Biggest Success
The part of the project I am most proud of is completing a fully functional Android application from start to finish. Before this course, I had programming experience but had never actually developed a mobile app. By the end of the project, I had built an app with user login, SQLite database storage, multiple screens, and working navigation between multiple different activities. Completing this project gave me a much better understanding of the entire development process and gave me more confidence that I can keep building apps in the future.
